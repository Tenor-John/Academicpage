3 正式测试 主持人/AI 使用

正式测试不是问卷。它是用上一步的原始问题，进行 3–5 轮必要追问，最后输出一个下一步具体动作和可检查结果。

当前页面先提供“人工主持版”的记录框。后续可以把这里接入 Netlify Function + OpenAI API，让 AI agent 自动追问和生成结果。

请在看完“测试结果摘要”后填写。这里的“处理方向”指刚才先从哪里处理你的问题；“下一步具体动作”指 1–2 天内能做的一件事；“可检查结果”指做完后能拿出来看的东西。
