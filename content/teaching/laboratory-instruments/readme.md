## 📚 主要内容包括：

### 🏠 实验室内仪器
- **离心机** - 样品分离和富集
- **冷冻干燥机** - 样品冷冻干燥处理  
- **高效液相色谱(HPLC)** - 有机化合物分离分析
- **质谱仪** - 分子质量和结构分析
- **超精细微量天平** - 精密称量（μg级别）
- **酶标仪** - 多功能光谱检测
- **万能拉伸机** - 材料力学性能测试
- **傅里叶红外(FTIR)** - 分子振动光谱分析

### 🏛️ 实验室外仪器
- **扫描电子显微镜(SEM/EDS)** - 表面形貌和元素分析
- **X射线衍射(XRD)** - 晶体结构分析
- **拉曼光谱** - 分子振动和晶格结构
- **X射线光电子能谱(XPS)** - 表面元素和化学态分析
