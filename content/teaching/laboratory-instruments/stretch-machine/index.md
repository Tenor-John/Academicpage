Universal Testing Machine Operation Guide

## 📋 设备概述 | Equipment Overview

万能拉伸机是用于测试材料力学性能的重要设备，可以进行拉伸、压缩、弯曲等多种力学测试。

The Universal Testing Machine is essential equipment for testing mechanical properties of materials, capable of tensile, compression, bending, and other mechanical tests.

## 🔧 传感器更换步骤 | Sensor Replacement Steps

{{< step step="1" title="准备工作" >}}
1. 关闭设备电源
2. 确保横梁处于安全位置
3. 准备必要的工具
4. 检查新传感器规格
{{< /step >}}

{{< step step="2" title="拆卸旧传感器" >}}
1. 断开电缆连接
2. 松开固定螺栓
3. 小心取下传感器
4. 检查连接部位
{{< /step >}}

{{< step step="3" title="安装新传感器" >}}
1. 清洁安装表面
2. 正确定位传感器
3. 紧固连接螺栓
4. 连接电缆线路
{{< /step >}}

{{< step step="4" title="校准测试" >}}
1. 重新启动设备
2. 进行零点校准
3. 执行标准测试
4. 验证数据准确性
{{< /step >}}

## ⚠️ 安全注意事项 | Safety Precautions

{{< callout type="danger" title="安全警告" >}}
操作过程中请严格遵守以下安全规定：
{{< /callout >}}

1. **人员安全**：
   - 测试过程中保持安全距离
   - 佩戴必要的防护设备
   - 熟悉紧急停止按钮位置

2. **设备安全**：
   - 定期检查设备状态
   - 避免超载使用
   - 及时进行维护保养

3. **样品安全**：
   - 正确固定试样
   - 预测断裂位置
   - 安全处理破碎试样

## 🔧 常见问题解决 | Troubleshooting

### Q1: 传感器数据异常？
**解决方案**：
- 检查电缆连接
- 重新校准零点
- 确认传感器规格

### Q2: 软件无法启动？
**解决方案**：
- 检查软件版本
- 重新安装驱动
- 联系技术支持

### Q3: 测试数据不准确？
**解决方案**：
- 验证校准状态
- 检查试样安装
- 确认参数设置
