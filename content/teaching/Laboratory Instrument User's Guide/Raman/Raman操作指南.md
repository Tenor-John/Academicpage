# 操作流程
## 显微镜调试
1. 先打开白光照明，在电脑界面上点击“摄像头”，打开显微镜观察。镜头下有白光。
2. 将样品放置于玻璃基板上（薄膜直接放置在基板上，粉末针尖取样，载玻片压平，粗糙的粉末，研磨后再测）
3. 有马赛克调不清楚，点十字叉rescale一键复原
4. 蓝色镜头用于矫正，我们不需要用
5. 找特殊点，即便是污染物也可以，只要调清楚了就可以了

**粗调焦：**先用5倍物镜，在显示器上调焦距，找到感兴趣的区域，然后更换50倍物镜观察。不好估计焦距（2.35），使劲拧粗准焦螺旋往上（在显微镜上只用粗的，细调焦距用鼠标）

**细调焦：**挪动到想测试的点位置，用电脑左手边的小转盘，旋转细调焦，也可以左右移动。

鼠标左键按住图片拖动，左键双击到目标点也行，鼠标滚轮可以微调焦距。

6. 调完了，关掉仓门，关掉白光，等stop变灰再移动鼠标。

## 程序调试+开始测试
在最右侧栏中选择Acuisition下调整参数

Acuisition parameters中调参数，只需要调整四个空

Range（2个空）：修改为自己需要的波长范围，有两个空，最短到50nm，低于50nm和老师说，这部分需要看文献

Spectrum中调节

Acq. time(s)（1个空）：积分时间，信号很强就只积分1-2s，信号很弱就延长积分时间。（我用泡沫镍的样品能扫到30s）

Accumulation（1个空）：循环积分时间，毛刺很多就多扫描几次（2-3次）



在最下面的横栏中选择激光器，需要切换激光器时需要喊老师来矫正

功率百分数，稳定的样品几个mW，有机的要小于1mW

不知道什么最合适可以从最小的mW的尝试，如果变黑了肯定烧了，信号偏弱再往上加

光栅选1200可能合适 分辨率太弱600光栅，想看的清楚直接2400，前提是信号强

点最上面圆球开始测试

测试前关门，记住，白光照明关掉点stop右上角等变灰，

没有图片、点十字叉和最开始操作一样

看最强的峰，如果是平的可能超量程了，也可以调积分时间，

# 注意事项
302房间只能做可见光波段的，303可以到红外光，

302房间的是320mm焦长，303的分辨率高，800mm焦长

303的光栅是不动的，600的光栅，302的1200的光栅和303的600差不多

1200光栅，两边实验室的仪器都可以用

常用波长：532，638，785

266，325做荧光用的，473，1064适应于荧光背景特别强的样品，波长越长拉曼信号越弱

538有荧光背景，可以尝试638和785

光栅调节**分辨率**，越密强度越低，分辨率越高，分辨率强度平衡

在不烧的前提，提高激光功率，延长激光时间，

浅色样品，亮度10%，深色样品50%以上
