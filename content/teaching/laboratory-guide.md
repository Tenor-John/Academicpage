# 实验室仪器使用指南

本指南涵盖528Lab实验室常用仪器的操作方法和注意事项。

## 主要仪器列表

### 力学测试设备
- **万能拉伸机** - 材料力学性能测试
- **硬度计** - 材料硬度测量

### 分析仪器
- **HPLC** - 高效液相色谱分析
- **质谱仪** - 分子量和结构分析
- **SEM/EDS** - 扫描电镜和能谱分析
- **XRD** - X射线衍射分析
- **XPS** - X射线光电子能谱
- **拉曼光谱** - 分子振动分析

### 制备设备
- **离心机** - 样品分离
- **冷冻干燥机** - 样品干燥保存
- **超精细微量天平** - 精密称量

## 安全规范

{{< callout type="warning" >}}
**安全提醒**
使用任何仪器前，请务必：
1. 阅读操作手册
2. 接受安全培训
3. 穿戴防护用品
4. 了解紧急处理程序
{{< /callout >}}
